# Birthday Website - Ngọc Bích (14/09) 🎂✨

Trang web chúc mừng sinh nhật lung linh, huyền ảo dành riêng cho cô gái **Ngọc Bích (14/09)** với:
- 👧 Hoạt cảnh cô bé hoạt hình chuyển lá thư bí mật từ góc màn hình ra giữa và nút mở thư tương tác.
- 💌 Thiệp chúc mừng sinh nhật kính mờ (Glassmorphism) cùng nền nhạc acoustic du dương.
- 🎂 Bánh sinh nhật 3D Particle phát sáng rực rỡ với hàng nghìn hạt photon và ngọn nến bập bùng.
- 🔄 Chế độ xoay 3D 360 độ (Drag to Rotate) & bắn pháo hoa khi chạm màn hình.
- 🎵 Phụ đề lời bài hát chữ viết tay nghệ thuật đồng bộ theo nhịp điệu.
- 🎁 Hộp quà ảnh kỷ niệm Polaroid sang trọng.

## 🚀 Cách Chạy Dự Án
1. Nhấp đúp vào file `start.bat` (trên Windows).
2. Hoặc chạy lệnh:
   ```bash
   node server.js
   ```
   Sau đó mở trình duyệt tại: `http://localhost:5000`
